# Data setup

The project is based on the [Home Credit Default Risk](https://www.kaggle.com/competitions/home-credit-default-risk/data) competition dataset.

## Steps

1. Accept the competition rules on Kaggle.
2. Download the competition files.
3. Keep raw files locally under `data/raw/`.
4. Run the project notebook to produce processed model and dashboard tables.
5. Do not commit raw or generated customer-level data to the public repository.

The public repository intentionally includes only documentation, code, dashboard assets, and reproducibility instructions.
